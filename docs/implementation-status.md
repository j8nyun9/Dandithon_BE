# 개발 현황과 다음 순서

기준: 2026-11-07, 로컬 ZIP 기반 작업본. 모든 데이터와 계정은 시연용이며 운영·공개 배포 준비가 끝나지 않았습니다.

## 구현됨 (로컬 시연)

- 학생·관리자·기관 담당자 로그인, 지정된 5개 대학의 테스트 학생 계정 및 학기 소속.
- 공식 원문·출처·신청 URL·자격·기간·완료 확인 방식과 1~2축 가중치를 입력하는 미션 등록 API 및 관리자 화면. AI 제안은 담당자 확인 후 등록.
- 등록 미션 목록, AI 추천 호출(실제 키 없으면 명시적 모의), 신청 링크 클릭 기록.
- 학생 확인 요청 → 기관·관리자 승인/반려, CSV 일괄 승인 API, 동일 사용자·미션 중복 차단, 외부 ID가 제공된 경우 동일 ID 중복 차단.
- 승인된 시연 실적의 대학별 종합 및 6축 인정 기여량의 가중치 합산, 승인 취소 시 재계산.
- 기관별 조회·클릭과 현재 상태별 집계 API, 5명 미만 마스킹. 헌혈 데이터는 기관 집계에서 제외.
- SQLite 초기 스키마, 가상 데이터·시연 계정, API 예시와 Node 자동화 테스트.

## 부분 구현 또는 미구현

- 사용자·대학·학기 생성/관리와 실제 학교 소속 검증: 고정 시연 데이터만 존재.
- 보안·개인정보: 로컬 시연 로그인, 단순 권한 확인만 제공. 운영용 인증·RLS·학교 검증·속도 제한·데이터 보존/삭제 및 익명화 검토 필요.
- 미션: 모집 시작·마감일(한국 날짜 기준), 기간 변경·수동 마감 구현. 공고 본문 등 다른 항목의 수정, 실제 진위 및 이용권 검증은 미구현.
- AI: 실제 API 호출 경로는 존재하나 키를 통한 실 호출과 품질 평가 미검증. 추천의 자격·일정 엄격 필터 및 환각 평가 필요.
- 실적: 학생 파일 업로드와 공식 시스템 연동 없음. 다른 외부 ID로 들어온 같은 실적은 수동 대조 필요. 관리자의 CSV 업로드 화면은 없음.
- 리그: 임시 점수이며 기획의 참여율·완료율·분야 폭 공식, 정규화, 최소 참가자 정책, 부문별 정렬 화면 미구현. 실제 헌혈 실적의 리그 집계 제외.
- 기관 퍼널: API만 제공, 화면 미연동. 현재 상태 인원이며 누적 전환율이 아님. 소규모 마스킹만으로 익명성이 보장되지 않음.
- FE 홈과 기관 집계는 서버 데이터를 표시하며 시상·의연록은 준비 중.
- 배포: SQLite 로컬 서버; PostgreSQL/Supabase 마이그레이션 및 Vercel 호환 배포·운영용 인증 미구현.
- 검증: API 로직 자동화 테스트와 FE 타입 검사. 실제 AI 호출·브라우저 전체 흐름·운영 DB·배포 환경 검증은 미완료.

## 기능 추가 순서

1. **미션 등록 화면 — 이번 단계:** AI 구조화 제안과 수동 확인, 원문·출처·신청 URL·복합 분류 등록. 로컬 테스트로 확인.
2. **모집 상태 — 이번 단계:** 시작·마감일을 구조화해 기간 밖 미션의 추천·신청 클릭을 막고, 관리자 기간 변경·수동 마감을 제공.
3. **관리자 실적 처리:** CSV 업로드 화면과 처리 결과, 중복·취소에 관한 검증 보강.
4. **기관 퍼널 화면:** 클릭/기관 확인 상태 분리 및 소규모 셀 보호를 표시.
5. **실제 AI 검증:** 키가 준비되면 실 호출·원문 기반 추출·추천 검증 및 실패 동작 점검.
6. **리그 정책과 화면:** 팀이 확정한 산식·최소 인원·헌혈 정책에 맞춰 계산과 6부문 순위 구현.
7. **배포 준비:** PostgreSQL·운영용 인증/권한, 보안·개인정보, FE 남은 목업 교체, 배포 및 제출 점검.

각 단계는 구현 후 테스트와 시연 방법을 남기고, 외부 계정 변경이나 GitHub 반영은 별도 지시에 따라 진행합니다.
